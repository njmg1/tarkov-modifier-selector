# KORD BREACH 모디파이어 시뮬레이터 <sub>v0.23</sub>

Escape from Tarkov · KORD BREACH 시즌 1의 모디파이어(특성 퍽) 39종을 한글로 번역하고,
조합해서 통과 여부를 확인하는 페이지입니다. (1.1.0.0.46608 시즌 런칭 밸런스 반영)

**https://njmg1.github.io/tarkov-modifier-selector/**

> 공식 한글화 번역이 아닙니다. 수치는 시즌 시작 전 변경될 수 있습니다.

## 규칙

선택한 모디파이어의 **합계가 0 이상**이면 통과합니다.

| 분류 | 개수 | 값 | 의미 |
|---|---|---|---|
| Global | 6 | — | 항상 적용, 비용 없음 |
| Personal Positive (퍽) | 19 | 음수 | 포인트를 **소모** (전부 선택 시 −74) |
| Personal Negative (디버프) | 14 | 양수 | 포인트를 **획득** (합계 +50, 배타 규칙 때문에 실제 최대 +49) |

디버프로 벌 수 있는 건 최대 +49뿐이라 모든 퍽을 살 수는 없습니다. 그게 이 시뮬레이터의 전부입니다.

## 동시 선택 불가 (1.1.0 공식 규칙)

시즌 런칭 빌드가 배타 규칙을 공식 공개해서, 추론이 아니라 **공식 목록 18쌍**을
그대로 반영합니다 (`data.js`의 `EXCLUSIONS`, 전부 `kind: 'official'`).

- 스탯 상반 계열: 혈전성향×혈우병 · 튼튼한뼈×골다공증 · 갈증감소×다갈증 ·
  다식증×만성피로 · 젊음×만성피로 · 젊음×탈진 (사전 추론 6쌍 전부 공식 확정)
- 스킬 성장 계열: 평범함×{무능·헤라클레스·타르코프슈터·PRODIGY} · PRODIGY×무능
- 신규 확인: 마라토너×스프린터 · 마라토너×탈진 · 다식증×젊음 · 다식증×탈진 ·
  스프린터×세번째다리 · 인성이슈×세번째다리 · LUCKY×UNLUCKY

주의: 인성이슈×세번째다리는 **디버프끼리** 배타라, 디버프 합계는 +50이어도
실제로 벌 수 있는 최대치는 +49입니다.

여전히 **같이 선택 가능한** 조합 (공식 목록에 없음):

- `THE TARKOV SHOOTER` + `INCOMPETENT` — 후자가 "볼트액션 제외"를 명시
- `KAPPA PROTOCOL` + `BROKEN SECURE CONTAINER` — 카파를 받고 제한될 수 있음

## 다국어 (한국어 / 日本語 / English)

배너의 언어 선택기로 전환합니다. 기본은 한국어, 선택은 `localStorage`에 저장됩니다.

- 모디파이어 39종의 제목·설명, 상단 툴바, 사이드바/하단 시트, 배타 조합 안내,
  모달, 공유 이미지까지 전부 언어를 따라갑니다. 문자열은 `data.js`의 `STRINGS`에 모여 있습니다.
- 영어는 게임 원본 텍스트(`en` 배열)를 그대로 씁니다. 한국어 제목·설명은
  2026-08-04 공개된 (준)공식 한글화를 따르고, 일본어는 팬 번역입니다.
- 채널명은 한국어에서만 "노잼망겜", 일본어·영어에서는 "NJMG"로 표시됩니다.

## 이미지로 공유하기

"이미지 저장"을 누르면 선택한 조합을 캔버스에 그려 미리보기 모달을 띄웁니다.
iOS Safari가 `<a download>`를 무시하고 파일 앱으로 떨어뜨리는 문제 때문에,
다운로드 대신 이미지를 먼저 보여주고 거기서 저장/공유하게 만들었습니다.

- **이미지 복사**: Clipboard API로 PNG를 클립보드에 직접 씁니다 (Ctrl/Cmd+V로 채팅창에 바로 붙여넣기).
  지원 브라우저에서만 버튼이 뜹니다.
- **공유**: Web Share API (`navigator.share`)가 파일 공유를 지원하는 환경(iOS/일부 데스크톱)에서만 노출됩니다.
- **다운로드**: 항상 가능한 최후 수단.
- 폰에서는 이미지를 길게 눌러 저장할 수 있습니다 (data URI라 롱프레스 메뉴가 뜹니다).

## 획득 가능 업적

사이드바(선택 목록) 아래에 현재 조합으로 노릴 수 있는 시즌 업적 8종이 표시됩니다
— 업적별 글리프 아이콘 + 충족 여부(진행도) + **어떤 특성이 필요한지 자동 생성된
조건 문구**(예: "다음 중 5개: 마라토너 · 젊음 · …")가 붙고, 레벨 30·카파 획득 같은
인게임 조건은 그 뒤에 이어집니다. 특성과 무관한 업적 4종은 맨 아래 한 줄로 표기.
폰에서는 바텀 시트 상단에 아이콘 8개짜리 스트립으로 압축 표시(충족 시 점등).
카파 프로토콜을 선택하면 「우리 집에는 하드코어가 있다」는 **달성 불가(⚠)**로
표시됩니다 — 컨테이너가 시작부터 지급되면 업적이 요구하는 '획득'이 성립하지
않는다는 인게임 확인 사항 반영. 패널 제목 옆 **조합①/조합②** 버튼은 검증된
최소 로드맵 두 캐릭터(카파 만능 ±0 / 맨몸 하드코어 +36)를 원탭으로 적용하며,
적용된 카드에는 업적 필수 여부가 **고정**(초록)/**자유**(점선) 코너 배지로
표시됩니다 (초기화·랜덤·슬롯 불러오기 시 배지 해제).
데이터는 `data.js`의 `ACHIEVEMENTS` (인게임 업적 화면 기준).

## 랜덤 뽑기 / 프리셋 슬롯

툴바의 "랜덤"은 배타 규칙을 지키면서 합계 0 이상이 되는 조합을 하나 무작위로
뽑습니다 (재미용). "프리셋"은 이 브라우저에 **최대 3개**까지 조합을 저장하는
슬롯 패널입니다 — 슬롯마다 불러오기/덮어쓰기/비우기가 되고, 이름은 저장 시각으로
붙습니다. 현재 선택(임시)은 자동저장되지만 슬롯에는 명시적으로 저장할 때만
들어갑니다. "이미지 저장"을 누르면 저장 여부(이미지만 / 저장하고 이미지)를 먼저
묻습니다.

슬롯에 저장하면 그 조합이 익명(브라우저별 랜덤 id)으로 구글 시트에 집계됩니다 —
어떤 특성을 사람들이 실제로 고르는지 보려는 용도이며, 로그인·개인정보는 없습니다.
수집 엔드포인트 설정은 `dev/sheet-collector.gs` 참고. `index.html`의 `SHEET_URL`이
비어 있으면(또는 `file://` 로컬 실행이면) 수집은 꺼집니다.

## 구조

```
docs/                 GitHub Pages가 서빙하는 디렉터리
  index.html          UI 전체 (CSS·JS 인라인)
  data.js             모디파이어 36종 (이름·값·영문/한글 설명)
  icons.js            아이콘 36개, data URI (생성물)
  char.js             마스코트 이미지, data URI (생성물)
  icons/              94×94 알파 PNG (생성물)
  assets/
    promo_banner.jpg  마스코트 원본
    character.png     배경 제거한 마스코트 (생성물)
    og.png            링크 미리보기 썸네일 (생성물)
  build_icons.py      source/blocks/*.png → icons/, icons.js
  build_char.py       assets/promo_banner.jpg → assets/character.png, char.js
  dev/                검증용 (배포에는 영향 없음)
source/
  blocks/             원본 모디파이어 블록 PNG 36장
  modifier-screenshot.jpeg
```

이미지는 전부 **data URI로 인라인**되어 있습니다. Chrome이 `file://`에서 CSS
`mask-image`의 상대 경로를 가져오지 않아 아이콘이 빈 칸으로 뜨기 때문이고,
덕분에 페이지를 그냥 열어도 정상 동작합니다.

## 생성물 다시 만들기

```sh
cd docs
python3 build_icons.py     # Pillow, numpy 필요
python3 build_char.py
```

## 검증

```sh
cd docs
./dev/verify.sh            # 헤드리스 Chrome, 데스크톱/폰 두 뷰포트에서 391개 어서션
```

`dev/shot.mjs`는 CDP로 브라우저를 몰아 스크린샷을 찍습니다. Chrome의 `--screenshot`
플래그는 뷰포트 지정을 무시하고 이미지 디코드를 기다리지 않아, 마스크 아이콘이
빈 칸으로 찍힙니다.

## 출처 주의

- 한글 **설명문**은 원본 이미지의 자막을 그대로 옮긴 것입니다. 단 세 장
  (`09`, `28`, `32`)은 원본이 잘려 있어 번역자가 문장을 마저 채웠습니다.
- 한글 **제목**(`koName`)은 원본에 없습니다. 이 저장소에서 붙인 이름입니다.
- 신규 3종(PRODIGY/LUCKY/UNLUCKY, id 37–39)의 아이콘은 블록 아트가 나올 때까지 임시 자리표시자입니다.
