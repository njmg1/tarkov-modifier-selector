## 자료 출처

한국어 커뮤니티 카드 시트(2936×4094)에서 옮겼습니다. 공통 6 + 긍정 31 + 부정 25 = 62종.
시즌 1과 달리 원본이 한국어라 번역 과정이 없고, 페이지도 한국어 전용입니다.

| 분류 | 개수 | 값 | 의미 |
|---|---|---|---|
| 전체 공통 | 6 | — | 항상 적용, 비용 없음 |
| 개인 긍정 (퍽) | 31 | 음수 | 포인트를 **소모** (전부 선택 시 −97) |
| 개인 부정 (디버프) | 25 | 양수 | 포인트를 **획득** (합계 +74, 배타 1쌍 때문에 실제 최대 +73) |

## 시즌 1에서 가져온 가정

시즌 2 자료에는 **점수 한도 규칙이 적혀 있지 않습니다.** 그래서 시즌 1 규칙을 그대로
적용했습니다 — 선택한 특성의 **합계가 0 이상이면 통과**. 페이지 하단에도 가정이라고
표시해 두었습니다.

## 동시 선택 불가 (추정)

시즌 2는 배타 목록을 공개하지 않았습니다. `data.js`의 `EXCLUSIONS` 22쌍은 전부
`kind: 'inferred'` — 효과 설명이 정면으로 반대이거나, 시즌 1에서 같은 쌍이 공식
배타로 확정됐던 경우만 넣었습니다. UI에도 "추정"으로 표시됩니다.

반대로 시즌 1 공식 목록이 **허용**했던 조합은 막지 않았습니다. 예를 들어
카파 프로토콜 + 고장 난 보안 컨테이너는 시즌 1에서 동시 선택이 가능했습니다.

## 알려진 불확실성

- **길거리세** — 원본 자료에서 제목 첫 글자가 아이콘에 가려져 "거리세"만 읽힙니다.
  시즌 1의 STREET TAX(보호비)와 효과가 같아 "길거리세"로 추정했고, 카드에 ◆ 표시를
  달아 두었습니다.

  (`ACHIEVEMENTS`에 데이터를 넣으면 다시 나타납니다).
